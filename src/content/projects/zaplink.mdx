## Overview

Zaplink is a URL shortener with custom short links, click analytics, and link management. It packages those features behind a REST API built with TypeScript, Node.js, and Express, with MongoDB for storage.

The core interaction is small: provide a destination, get a shorter link, and send visitors to the original URL. Link management and analytics build on that basic redirect.

## The redirect flow

A short link connects a compact code to a destination. When someone follows the link, the application looks up the code and redirects the visitor.

```text
Short link → Look up destination → Redirect
                      ↓
                 Click analytics
```

The lookup is the central operation. Custom links use the same idea, but let the person creating the link choose a recognizable code.

## Link management and analytics

A redirect is only one part of managing links. Zaplink also provides a way to work with existing short links and understand their clicks.

These features make the project more than a one-route redirect demo. The API needs to represent a link as a resource that can be created, retrieved, and managed, while analytics describe activity around that resource.

## Technology choices

- **TypeScript** describes the data moving through the API.
- **Node.js and Express** provide the REST API and redirect handling.
- **MongoDB** stores links and the application data behind link management.

## Engineering focus

A shortener makes data integrity easy to see. Each short code should identify one destination, and a requested custom code can already belong to another link.

It also creates two different paths to think about: managing links through an API and serving visitors who follow them. Keeping the redirect path straightforward helps keep the core interaction easy to reason about as management features grow.
